Exam trap 1: Web ≠ Internet. The internet is the hardware (cables, routers, phones). The web is a service that runs on top of it — like traffic on a road. No road, no traffic.
Exam trap 2: Web page ≠ Website. One page is a page; a group of linked pages with one domain name is a website. A book page vs. the whole book.
Exam trap 3: A web server is the computer/software that stores and sends pages. Web hosting is the service a company sells you to keep your files on that server, online 24/7.

World Wide Web

Exam definition — memorise this line

A worldwide collection of interlinked web pages stored on web servers and accessed through the internet using a web browser.

Each line is a hyperlink. Tap a page to "follow" it.

INFO Pick a page

Tap any page in the diagram to see what it does and how it is linked to other pages.

history: 0 hops

≠ Internet vs Web

Internet = the global network of computers and cables. It carries email, WhatsApp, games and the web.

World Wide Web = one service that uses that network: pages written in HTML and joined by hyperlinks.

So the web needs the internet, but the internet is not only the web.

1969–91 How the web was born

  • 1969 — ARPANET connects 4 computers. The internet starts.
  • 1983 — TCP/IP becomes the standard: computers can talk to each other.
  • 1989 — Tim Berners-Lee (CERN) proposes the World Wide Web.
  • 1990–91 — He writes the first browser, the first web server and HTML.
  • 1993 — Mosaic browser makes the web easy for everyone.

Term 3 of 9

Website — 4 pages, but only 1 website

Exam definition — memorise this line

A collection of related web pages that share one domain name, are stored on the same web server and are joined by hyperlinks.

Tap the menu inside the page — the URL bar changes, but the domain name stays the same.

4 → 1 Why 4 pages are 1 website

  • Same domain: every page starts with www.school.edu.pk
  • Same server: all 4 files sit in one folder on one web server
  • Linked: the menu uses hyperlinks, so you can move between pages
  • Related: all 4 pages are about the same school

PATH One domain, different files

www.school.edu.pk/index.html  ← home page
www.school.edu.pk/about.html
www.school.edu.pk/academics.html
www.school.edu.pk/contact.html

Only the path changes. That is why it is one website, not four.

Exam trap: "Web page" = one file. "Website" = the whole set of files under one domain. If a question says "a collection of related web pages", the answer is website.

Web Browser — every button explained

Exam definition — memorise this line

Application software that requests web pages from servers, reads the HTML and renders the page on the user's screen.

Tap any button above, or click a link inside the page, to learn what it really does.
View source — the raw HTML the server sent
Browser ≠ search engine. Chrome, Firefox and Edge are browsers. Google, Bing and Yahoo are search engines — websites you open inside a browser.
Four jobs of a browser: 1) send an HTTP request 2) receive the HTML 3) read (parse) it 4) render it on screen.

Search Engine — crawl, index, then rank

Exam definition — memorise this line

A program/website that searches an index of web pages collected by crawlers and lists the most relevant results first.

1 Crawl & build the index

A crawler visits pages and records every word. The result is an inverted index: word → list of pages.

docs 0 unique terms 0 postings 0

2 Search it with real scoring

score = (1 + log tf) × log(1 + N/df)

Press Crawl 9 pages first, then search.
Why "pizza" returns nothing: the index has no posting for it. A real search engine would answer "no results found" — that is zero results, not an error.
Three steps of a search engine: crawl (collect pages) → index (store the words) → rank (most relevant first). Order matters. Never say "the search engine searches the whole internet live".
Term 7 of 9

Home Page — the door of the website

Exam definition — memorise this line

The main/first page of a website, usually index.html, which opens when the domain name is entered and links to every other page of the site.

Type only the domain name (no file name) and the server sends you the home page automatically.

= Why index.html?

Web servers are configured to look for a default file — index.html — when the URL has no file name. So www.school.edu.pk and www.school.edu.pk/index.html open the same page.

Exam trap: the home page is not "the first page of the internet" and it is not a browser's start page. It is the main page of one website. Try mysite.com in the Browser Lab — it opens only after you host it.

Exam trap: web server = the machine/software that answers requests. Web hosting = the service (usually paid, monthly) that rents you space on that server. Same idea as: "fridge" vs "cold storage service".
Term 9 of 9

Web Server — a request in, a response out

Exam definition — memorise this line

A computer (and the software on it) that stores web pages and sends them to browsers over HTTP/HTTPS, answering each request with a status code (200, 404, 500…).

waiting for a request
GET /index.html
your browserweb server · port 443
Request headers (browser → server)
— press a GET button —
Response headers (server → browser)
— no response yet —
Server log
[boot] server listening on 0.0.0.0:443
Status codes to memorise: 200 OK (file found) · 301 moved permanently (redirect) · 404 not found (file missing) · 500 server error (server's own bug).
HTTP vs HTTPS: both are protocols for asking and answering. HTTPS adds encryption (a padlock in the address bar). A web server listens for requests and answers with a status code + headers + the page.
Lab · all 9 terms together

Browser Lab — 4 websites, real behaviour

Type a URL, follow links, go back, view source. Try nowhere.xyz (DNS error) and techbooks.com/missing (404).

DNS lookup → HTTP GET → render. Watch this line.
DNS error vs 404 — the difference: a DNS error means the domain name itself does not exist, so no computer was found at all. A 404 means the computer was found and answered, but the file you asked for is not there.
One line to remember: DNS finds the server; the path finds the file on that server.
